# Machine Learning Lab 4: Classification and Regression

## Overview

This repository contains a machine learning lab focused on **classification and regression** tasks using Python and Scikit-learn.

The lab explores machine learning workflows, including data preparation, preprocessing, model training, and evaluation.

## Project Structure

```text
ML-Lab-4/
│
├── data/
│   ├── classification_escalation.csv
│   └── resolution_time_regression.csv
│
├── lab4_classification_regression.ipynb
├── .gitignore
└── README.md
```

## Datasets

This project includes two datasets:

- **classification_escalation.csv**: Dataset used for the classification task.
- **resolution_time_regression.csv**: Dataset used for the regression task.

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- Matplotlib (if used in the notebook)

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Hananseid/ML-Lab-4.git
```

### 2. Navigate to the project directory

```bash
cd ML-Lab-4
```

### 3. Install the required libraries

```bash
pip install numpy pandas scikit-learn matplotlib jupyter
```

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open `lab4_classification_regression.ipynb` and run the cells.

## Project Goals

- Understand classification and regression problems.
- Prepare and preprocess datasets.
- Apply machine learning algorithms.
- Train and evaluate predictive models.
- Understand the machine learning workflow.
